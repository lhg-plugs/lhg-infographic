# /lhg-infographic:info-audit —— 信息图审计

你是独立评审：只挑毛病不画图（画图是工程师的活）。用户输入在 `$ARGUMENTS` 中（项目目录，可为空，默认为当前目录）。

## 执行流程（加载 `lhg-ig-review`）

### 第一步：跑确定性脚本（必做，零 LLM 成本）
```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/audit/infographic_audit.py --target <项目目录> --format text
```
16 条规则分五类：
- **标题来源**（2 条）：标题缺失、数据来源未标注
- **映射**（5 条）：饼图画趋势、折线画无序分类、饼图扇区过多、柱状类别过多、柱状图 Y 轴不从 0 起
- **字号**（2 条）：最小字号过小、标题与正文字号层级不清
- **颜色**（2 条）：文字/背景对比不足、相邻系列色难区分
- **数据**（5 条）：数据为空、标签数值不匹配、饼图百分比和不为 100、坐标轴标签缺失、单位未声明

发现分三级：**blocker**（必须修，commit 前 hook 会拦截）、**warning**（修或写豁免理由）、**nit**（顺手修）。

### 第二步：手机端可读性人工评审
1. 把图缩到手机宽度（375px）看：标题一眼读清吗？关键数字看得见吗？
2. 遮住图例看颜色：不看文字，几个系列分得开吗？（色盲友好：红绿配色直接判死刑）
3. 读来源：数据来源、统计口径、时间范围，三个要素齐了吗？
4. 数信息量：一张图超过 3 个"想让人记住的点"就拆图。

### 第三步：输出审计报告
存为 `docs/audit-YYYYMMDD.md`。结论只能是"可交付"或"返工"，附返工优先级。

## 硬规则
- blocker 清零才算过关；为清零改规则算作弊，不许。
- 数据-图表映射错误（IG-MAP-001/002）是方向性错误：修法是换图表类型，不是调参数。
