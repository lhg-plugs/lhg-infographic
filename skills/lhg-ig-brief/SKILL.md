# lhg-ig-brief：需求澄清与数据整理

> 目标：开画前回答"给谁看、在哪看、记住哪句话"，并交出一份口径干净的数据。
> 核心纪律：**数据口径没对齐不选型**。一张图里混了两种口径，画得再好看也是错的。

## 1. 何时使用

- 用户甩过来一份数据/一篇文章说"做张图"时 → 必须先跑本 skill
- 数据已经整理好、只想选图表时 → 跳过本 skill，直接用 lhg-ig-chart
- 图已经画完、只想评审时 → 跳过本 skill，用 lhg-ig-review

## 2. 输入与输出

- **输入**：原始数据（表格/CSV/文章段落）+ 用途说明（可空，为空则问）
- **输出**：`data/` 下的干净数据 + `chart-spec.json` 的 `data` 字段（含单位、口径、时间范围备注）

## 3. 第一步：问清三件事

动笔前必须问（用户答不上来就给选项让他挑，不许跳过）：

1. **给谁看？**——专业人士 / 普通读者 / 领导汇报。三种受众的信息密度、术语深度完全不同。
2. **在哪看？**——手机竖屏 / 电脑 / 打印。手机是默认场景：750px 宽是硬约束。
3. **记住哪一句话？**——逼用户用一句话说出这张图的核心信息。说不出来，说明需求还没想清楚，先聊需求再画图。

## 4. 第二步：收数据（四个问题）

1. **数据全吗？**——缺失值标出来：是"没有数据"还是"数据为 0"？两者画出来完全不同，不许混为一谈。
2. **单位是什么？**——元/万元/亿元？人/万人？单位错一位，图就成造谣。单位必须写进 `chart-spec.json` 的 `y_label` 或 `unit`。
3. **口径一致吗？**——时间范围（自然年/财年？）、统计范围（全国/抽样？）、是否含税——混口径的数据先拆成两组，不许画在一张图里。
4. **时间范围？**——数据的起止时间必须明确，这是来源标注三要素之一（来源/口径/时间）。

## 5. 第三步：洗数据（输出干净数据）

1. 转成统一结构：`[{"label": "…", "value": 数字}, …]`，label 是人话，value 是纯数字（不许带"万""%"，单位放 `y_label`）。
2. 排序：时间序列按时间排，分类比较按数值排（从大到小），构成占比按数值排——不要用数据源的原始乱序。
3. 异常值复核：最大值/最小值跟用户确认一遍（"这个数对吗？"），离谱的数先核实再画。
4. 数据量：单张图数据点建议 ≤ 12 个；多了就聚合（按月→按季度）或拆图。

**诚实原则**：数据里的每个数字必须能追溯到来源；用户给的数据本身存疑，标注"数据未经核实"而不是美化它。不许编造数据凑数。

## 6. 第四步：定核心信息（一句话）

把第 3 步的"记住哪一句话"写下来，贴在项目显眼处。选型、绘制、评审三步都要回看这句话：

- 选型时问：这个图表类型能让这句话一眼被看到吗？
- 绘制时问：这句话对应的视觉元素最突出吗？
- 评审时问：遮住标题看图，能猜出这句话吗？猜不出就返工。

## 7. 反模式（这些做法一定翻车）

- **需求不清就开画**：画完三版用户说"不是这个意思"——需求澄清 10 分钟，返工 3 小时。
- **混口径**：2024 年自然年数据和 2023 年财年数据画一条线，专业人士一眼看穿。
- **单位藏起来**：Y 轴 12000，单位是"元"还是"万元"？不标就是耍流氓。
- **缺失值当 0 画**：断了的数据画成 0，趋势直接造假——缺失就是缺失，断开画并标注。
- **数据点贪多**：一张图塞 30 个柱子，手机上缩成牙签——聚合或拆图，没有第三条路。
- **美化存疑数据**：用户说"这个数大概是"，你画成精确值——标注不确定性，不许精确化猜测。

## 8. 自检与反馈

质检门（数据交付选型前自查）：

- [ ] 受众/场景/核心信息三件事已书面确认
- [ ] 数据无缺失值混淆（缺失已标注，未当 0 处理）
- [ ] 单位、口径、时间范围三要素齐全并写入 spec
- [ ] 异常值已跟用户复核
- [ ] 单张图数据点 ≤ 12 个（或已聚合/拆图）

标准冒烟用例：用本仓库 `fixtures/info-good/chart-spec.json` 的 `data` 为参照——label 人话、value 纯数字、单位在 `y_label`、来源三要素齐。

发现 bug 或有改进建议，以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-infographic/issues，正文写清"复现步骤 → 实际表现 → 期望表现"。

## 9. 附：数据核查清单（逐项打勾）

### 9.1 完整性
- [ ] 时间范围连续吗？缺的月份/年份标出来了吗？
- [ ] 分类齐全吗？"其他"类占比超过 30% 就要追问明细
- [ ] 异常值复核过吗？（最大值/最小值跟用户确认）

### 9.2 口径
- [ ] 时间口径：自然年 / 财年 / 滚动 12 个月——写下来
- [ ] 统计范围：全国 / 抽样 / 部分渠道——写下来
- [ ] 含税/不含税、名义/实际——写下来
- [ ] 同一张图的指标口径一致吗？

### 9.3 单位与格式
- [ ] 单位明确（元/万元/亿元，人/万人）
- [ ] value 是纯数字（不许带"万""%"）
- [ ] label 是人话（"2024年7月"不许写成"202407"）

### 9.4 来源
- [ ] 每个数字能追溯到来源文件/链接吗？
- [ ] 来源三要素齐了吗？（来源/口径/时间）
- [ ] 存疑数据标注了吗？（不许精确化猜测）

## 10. 附：口径对齐话术（问用户的标准问法）

- "这个数据是自然年还是财年？"
- "统计范围是全国还是抽样？抽样的话样本量多少？"
- "单位是元还是万元？这个数 12000，后面跟什么单位？"
- "2023 年 5 月的数据缺失，是确实没有，还是还没统计？"
- "这两个指标的口径一样吗？一个含税一个不含税可不能画一起。"

## 11. 附：需求澄清纪要模板

```markdown
## 信息图需求纪要（YYYY-MM-DD）

- 主题：一句话（如"Q3 销量复盘"）
- 受众：普通读者 / 专业人士 / 领导汇报
- 场景：手机竖屏 / 电脑 / 打印
- 核心信息（一句话）：如下半年销量明显加速
- 数据文件：data/xxx.csv（N 行）
- 单位/口径/时间：销量（万件），全国口径，2026-07 至 2026-09
- 异常值复核：8 月 156 万件已确认无误
- 交付物：output/xxx.html + 本纪要
```

纪要的意义：三个月后回看，还能知道这张图为什么长这样。口头约定的需求等于没有需求。

## 12. 附：一句话速记

数据不清不选型，口径不明不开画。每个数字有来源，每张图只讲一件事——这是信息图的"宪法"。

## 13. 附：需求澄清反问清单（用户说"随便做"时用）

- "这张图发出去，你最希望读者记住哪一个数字？"
- "如果只能保留一个图表元素，你留哪一个？"
- "有没有绝对不能出现的数据？（涉密/未公开）"
- "竞品/对标的图长什么样？发我看看，我们要避开还是超越？"
- " deadline 是什么时候？时间紧我就用最稳的方案，不玩花的。"
